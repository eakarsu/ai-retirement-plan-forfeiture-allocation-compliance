# Retirement Plan Forfeiture Allocation Compliance

Ensure forfeitures are recognized timely and used only for plan-authorized contributions, expenses, or participant allocations.

**Primary buyer:** 401(k) plan sponsors and recordkeepers. **Evidence:** plan documents, participant balances, vesting, terminations, forfeitures, employer contributions, expenses, correction rules, allocations, and filings.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Plan document rules
- Participant vesting ingestion
- Termination event control
- Forfeiture recognition
- Restoration obligation
- Forfeiture account ledger
- Permitted use validation
- Contribution offset calculation
- Plan expense payment review
- Participant reallocation
- Year-end deadline monitoring
- Operational failure detection
- Correction calculation
- Audit evidence package
- Plan forfeiture analytics

Run `./start.sh`, then open <http://127.0.0.1:4676>. API: `5676`.
